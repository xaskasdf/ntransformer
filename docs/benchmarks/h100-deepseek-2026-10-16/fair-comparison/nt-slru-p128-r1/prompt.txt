Transformer inference is a sequence of dependent computations. A request begins with a prompt, and the model processes its tokens to construct attention state. Once this preparation is complete, it predicts a new token, appends that token to the history, and repeats the process. The time to the first token and the time between later tokens describe different parts of the user experience.

An inference engine must place weights, activations, and cached attention data somewhere in the memory hierarchy.
